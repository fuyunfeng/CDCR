# CDCR · 儿童认知发展与指令接收

> 帮助 **6-9 岁儿童**（尤其是 **感统失调儿童**）提高专注力与执行能力的可操作指南
>
> Children’s Cognitive Development & Command Receiving — A Practitioner-Oriented Guide

---

## 项目背景

本项目系统整理了儿童认知发展、专注力培养、感统失调（SPD）干预等领域的方法论，形成**可操作的指南**。

旨在帮助家长、教师、特殊教育工作者在日常场景中识别「做不到」背后的真实卡点，并提供科学的干预策略。

---

## 核心内容

### 1. 认知框架（第 1-4 章）

- 指令接收的 **5 环节流水线**：感知输入 → 注意 → 语义理解 → 计划执行 → 监控反馈
- **信息块（Chunk）** 机制与工作记忆容量（实际约 4 块，不是 Miller 当年的 7±2）
- 影响专注力的 **4 大根源**：神经发育、认知加工、情绪动机、环境支持

### 2. 实践应用（第 5 章）

- 8 岁孩子的**半结构化时间表**（含可视化 HTML 模板）
- 任务块设计原则、常见误区、有效性信号

### 3. 感统失调（SPD）专项（第 7 章）

- **三大类型** × **七大感觉系统**详解
- 家庭**感统"食谱"**（Sensory Diet）
- 学校/课堂支持策略
- 证据等级与争议（SPD 在 DSM-5 未收录）

### 4. 6/7/8/9 岁差异化指南（第 8 章）

- 每个年龄的神经特点、易踩坑、训练重点

### 5. 执行功能训练活动库（第 9 章）

- **20 个**可立即执行的游戏（按材料/步骤/时长/难度递进）
- 涵盖工作记忆、抑制控制、认知灵活性、计划组织、自我监控、启动

### 6. 家长/教师话术库（第 10 章）

- **18 个**常见场景的错误/正确示范 + 元原则

## 核心理念

- 孩子「做不到」，**未必是态度问题**，可能是认知流水线的某一环堵了
- 感统问题**不会自发改善**，需要家庭+专业双轨干预
- **关系先于教育**，修复永远不嫌晚
- 行为可批评，人不可批评

## 使用建议

1. **第一次阅读**：先通读主文档，建立整体框架
2. **日常查阅**：根据场景翻到具体章节（如"写作业崩溃"→ 第 10.3 节）
3. **干预实践**：用 [进展日志.md](进展日志.md) 记录每次干预的问题、方法、效果
4. **反馈改进**：发现指南中需要修订的地方，记到日志的「反馈回路」区，定期整理回主文档

## 重要提醒

⚠️ **本指南基于公开发表的研究和临床实践整理，不构成医疗诊断。**

- 怀疑孩子有 APD/SPD/ADHD/DLD 等神经发育差异时，请寻求专业评估
- SPD 评估找 **作业治疗师（OT）**；ADHD 找发育行为儿科；APD 找听力学家/言语病理学家
- 任何干预方法都需要在「匹配年龄 + 匹配个体」的前提下使用
- 不要被"包治百病"的感统馆宣传误导（详见第 7.6 节）
